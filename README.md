## Entry

## How it runs

`main.py` (Python 3.13, standard library only) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) with no
trailing newline, and prints it. It self-checks the gate first: 1–200
characters, not only whitespace, exactly one line.

```sh
python3 main.py
```
